# دعوة زفاف محمد أديب طويل ورزان بطايحي

موقع دعوة ثابت مبني على ملفات قالب حُلم وردي المرفقة.

## تعديل بيانات الدعوة

عدّل الأسماء والتاريخ والمكان والبرنامج والنصوص والروابط ومسارات الصور والفيديو في [`invitation.config.js`](invitation.config.js). الأصول المحلية موجودة داخل `assets/`.

تأكيد الحضور يعمل محليًا على جهاز الضيف؛ لا تُرسل الردود إلى خادم أو تُحفظ مركزيًا. روابط التواصل والطلب تستخدم رقم واتساب المحدد في الإعدادات.
